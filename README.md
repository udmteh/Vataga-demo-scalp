# 🎯 Vataga Demo Scalp (by CGTehnik)

> **Локальный эмулятор биржи и прокси-шлюз для терминала Ватага (Vataga Terminal)**  
> Позволяет отрабатывать скальперские стратегии и торговать в реальных стаканах **Binance Futures** и **Bybit V5 Linear** без риска реальных средств (Paper Trading).

---

## ⚡ Особенности

* **Настоящие рыночные данные**: Стаканы L2, кластеры, графики и лента сделок идут напрямую с реальных бирж в режиме реального времени.
* **Локальный движок матчинга (Matching Engine)**:
  * Рыночные ордера исполняются мгновенно по ценам Best Bid / Best Ask.
  * Лимитные заявки выставляются в стакан, отображаются в терминале и автоматически исполняются при касании цены рынком.
  * Полная поддержка снятия лимиток крестиком `[X]` прямо в стакане, через горячие клавиши отмены и через кнопку «Снять все» (`Cancel All`).
* **Раздельный учёт бирж**: Независимые позиции, балансы и плечи для Binance Futures и Bybit V5 Linear.
* **Безопасность и автономность**: Не требуются реальные API-ключи бирж. Шлюз работает локально (`127.0.0.1`), перехватывая только торговые запросы и пропуская публичные котировки напрямую.
* **Автоматическая установка в 1 клик**: Встроенные скрипты сами прописывают прокси и демо-подключения в базы данных Ватаги (`proxies.db`, `exchanges.db`).

## 💻 Системные требования

| Компонент | Требование |
| :--- | :--- |
| **Операционная система** | Windows 10 / Windows 11 (64-bit) |
| **Python** | Версия **3.10** или выше (рекомендуется Python 3.11–3.13) |
| **Терминал** | Установленный терминал **Ватага (Vataga)** |

## 🚀 Пошаговая инструкция по запуску

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/udmteh/Vataga-demo-scalp.git
cd Vataga-demo-scalp
```

### Шаг 2. Установка Python-зависимостей
Откройте командную строку (cmd или PowerShell) в папке проекта и выполните:
```bash
pip install -r requirements.txt
```

### Шаг 3. Установка локального SSL-сертификата
Терминал Ватага обращается к биржам по безопасному протоколу HTTPS. Чтобы локальный шлюз мог обрабатывать торговые запросы, необходимо добавить самоподписанный сертификат шлюза в доверенные корневые сертификаты Windows:
1. Нажмите правой кнопкой мыши на файл `install_certificate.bat`.
2. Выберите **«Запуск от имени администратора»**.
3. Подтвердите установку (в окне консоли появится надпись `[SUCCESS] Certificate installed successfully!`).

### Шаг 4. Регистрация демо-подключений в Ватаге
Убедитесь, что **терминал Ватага закрыт**, после чего запустите скрипт интеграции:
```bash
python install_to_vataga.py
```
Скрипт автоматически:
* Добавит локальный прокси `127.0.0.1:8989` в настройки Ватаги.
* Создаст два готовых демо-подключения:
  * **Binance Futures [by CGTehnik]**
  * **Bybit Linear [by CGTehnik]**

### Шаг 5. Запуск шлюза
Запустите шлюз двойным кликом по файлу:
```text
start_gateway.bat
```
*(или через консоль: `python gateway.py`)*

В окне появится статус:
```text
===========================================================
  🚀 VATAGA PAPER GATEWAY by CGTehnik ACTIVE!
  • Proxy Port (Vataga connects here): 127.0.0.1:8989
  • Mock SSL Engine: 127.0.0.1:8990
  • Virtual Balance: $100.00 USDT
  • Supported Exchanges: Binance Futures & Bybit V5 Linear
===========================================================
```

### Шаг 6. Торговля в Ватаге
1. Откройте терминал **Ватага**.
2. В окне «Подключения» активируйте переключатели напротив:
   * `Binance Futures [by CGTehnik]`
   * `Bybit Linear [by CGTehnik]`
3. Статус сменится на зелёный `F` с пингом ~1 мс.
4. Выберите нужные инструменты в стаканах и торгуйте!


## ⚙️ Управление балансом и настройками

История торговли, открытые позиции и баланс хранятся в JSON-файле:
```text
data/vataga_demo_trades.json
```
* **Изменение баланса**: Вы можете в любой момент изменить значение `"balance"` в этом файле на любую желаемую сумму при перезапуске шлюза.
* **Удаление подключений**: Если вы захотите полностью удалить демо-подключения и прокси из терминала Ватага, закройте терминал и выполните:
  ```bash
  python uninstall_from_vataga.py
  ```

## ❓ Решение возможных проблем (Troubleshooting)

### 1. Терминал пишет «Сетевые проблемы» / индикатор серый
* Убедитесь, что `start_gateway.bat` запущен и окно консоли активно.
* Проверьте, что сертификат установлен (`install_certificate.bat` запущен от имени администратора).
* Убедитесь, что сторонний VPN или фаервол не блокирует порты `8989` и `8990`.

### 2. Ошибка «Address already in use» при запуске шлюза
Это означает, что предыдущий процесс шлюза ещё остался в памяти. Завершите его через диспетчер задач (`python.exe`) или выполните в консоли:
```cmd
taskkill /F /IM python.exe
```

### 3. Лимитная заявка в стакане не снимается
Шлюз поддерживает автоматическую синхронизацию статусов отмены Bybit V5 и Binance Futures. Если ордер застрял, нажмите горячую клавишу отмены заявок в терминале Ватага или кнопку «Снять все» — шлюз принудительно очистит стакан.
